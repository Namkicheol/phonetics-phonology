Distinctive Feature 판별

distinctive feature는 segment를 더 작은 대비 단위로 나누어 natural class를 찾게 해 준다. 답안에서는 feature name과 feature value를 함께 써야 하는지 먼저 확인한다.

[+sonorant] / [−sonorant] · [+anterior] / [−anterior] · [+continuant] / [−continuant]
발문이 “feature value must be specified”라고 하면 [−sonorant]처럼 값까지 포함해야 한다.
기출 연결 · 2023 A-2: verb-forming suffix -en의 결합 조건을 [−sonorant]로 판별.

[−sonorant]와 Obstruent

obstruent는 일반적으로 [−sonorant]로 묶인다. stop, fricative, affricate가 여기에 들어가며, natural class를 묻는 문제에서 자주 쓰인다.

가능 패턴: stem-final obstruent + -en
차단 패턴: stem-final vowel / nasal / liquid + -en
기출 연결 · 2018 A-5: sonorant vs obstruent 구분. · 2023 A-2: [−sonorant] 답안.

Yod-dropping과 anterior

Yod-dropping은 /j/가 특정 segment 뒤에서 사라지는 분포를 feature로 일반화하는 유형이다. 최신 기출에서는 coronal 내부를 다시 anterior 값으로 가르는 방식이 핵심이었다.

[−anterior] vs [+anterior] · /j/-dropping · cluster environment
답안 순서: 데이터 분포 → feature 표 대조 → [±anterior] 값 확정 → cluster 환경 일반화.
기출 연결 · 2026 A-6: coronal, anterior, Yod-dropping.

Place Feature와 Phonotactics

coronal, labial, dorsal 같은 place feature는 cluster 허용 여부를 설명할 때 쓰인다. 예시의 허용/불허 목록을 natural class별로 재배열하는 것이 먼저다.

coronal obstruent + /r/ 가능 · coronal obstruent + /l/ 차단
