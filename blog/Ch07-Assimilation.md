# 임용 음운론 Ch.7 Assimilation 완전 정리: 동화의 방향·정도·Place/Voice/Manner

음운론 기출에서 **Assimilation(동화)** 단원은 다양한 각도로 출제된다. <span style="color:#3182ce;">**Place assimilation**</span> 방향 판별부터 <span style="color:#3182ce;">**iN- prefix**</span> 형태 결정, 복수·과거 형태소의 voicing 교체, <span style="color:#3182ce;">**il-/ir-**</span> 배분 조건까지 — 이 글은 서브노트에 정리된 핵심 규칙들을 **① 개념 정의** → **② 기출 맥락** → **③ 키텀 비교** → **④ 수험 팁** 4섹션으로 풀어낸다.

---

## ① 개념 정의 — 핵심 규칙을 영어 원문과 함께

### 1) Assimilation — 정의와 동기

**Rule summary**: Assimilation은 target이 adjacent trigger의 하나 이상의 phonological feature를 받아 두 sound가 더 유사해지는 process다.

<span style="color:#3182ce;">**Assimilation**</span>의 핵심은 인접 sound가 더 유사해지는 것이다. 이는 <span style="color:#3182ce;">**ease of articulation**</span>와 관련되며, <span style="color:#c53030;">**Dissimilation**</span>은 반대로 sound가 서로 달라지는 현상이다.

동화는 세 가지 독립 차원으로 분류된다:
- **방향(direction)**: Progressive vs Regressive
- **정도(degree)**: Total vs Partial
- **인접성(adjacency)**: Adjacent vs Non-adjacent

---

### 2) 방향 — Progressive vs Regressive

**Progressive assimilation**에서는 trigger가 target보다 앞에, **regressive assimilation**에서는 trigger가 target보다 뒤에 놓인다.

<span style="color:#3182ce;">**Progressive assimilation**</span>: 앞 sound가 뒤 sound에 영향 → 뒤 sound가 앞 sound를 닮아감. 영어에서 상대적으로 드묾.
<span style="color:#3182ce;">**Regressive assimilation**</span>: 뒤 sound가 앞 sound에 영향 → 앞 sound가 뒤 sound를 닮아감. 영어에서 더 흔함.

| | 방향 | 영어 빈도 | 대표 예 |
|---|---|---|---|
| **Progressive** | 앞→뒤 (trigger precedes) | 드묾 | cats [kæts]: plural /z/ → [s] after /t/ |
| **Regressive** | 뒤→앞 (trigger follows) | 흔함 | ten boys: /n/ → [m] / ___ /b/ |

<span style="color:#c53030;">**핵심 포인트**</span>: 여기서 다루는 영어 /n/의 Place assimilation은 Regressive다. following consonant의 place가 preceding /n/에 나타나는 방향이 출제 포인트다. 이 방향을 Progressive로 혼동하면 오답.

---

### 3) Place Assimilation — iN- prefix와 연음

대표적인 영어 nasal Place assimilation에서는 following consonant의 place feature가 preceding /n/에 나타난다. negative prefix /iN-/은 이 regressive pattern을 보여 주는 morphophonemic example이다.

<span style="color:#3182ce;">**Place assimilation**</span>: 인접 sound의 **place feature**를 닮아가는 동화. 영어 규칙:

| /n/ 환경 | /n/의 실현 | 예시 |
|---------|-----------|------|
| bilabial /p, b/ 앞 | → [m] | ten boys [tɛm bɔɪz], ten people [tɛm pipəl] |
| velar /k, g/ 앞 | → [ŋ] | ten girls [tɛŋ gɜːrlz], ten keys [tɛŋ kiːz] |
| 그 외(alveolar 앞) | → [n] | ten days, ten names |

**iN- prefix 형태 결정 규칙** (regressive place assimilation):

| 형태 | 환경 | 예시 |
|------|------|------|
| **im-** | bilabial /p, b, m/ 앞 | impossible, imbalance, immature |
| **in-** | alveolar /t, d, n, s/ 앞 (기본형) | indirect, intolerant |
| **iŋ-** | velar /k, g/ 앞 | inconclusive [ɪŋk-], ingratitude [ɪŋg-] |
| **il-** | /l/ 앞 (Manner assimilation) | illegal, illogical |
| **ir-** | /r/ 앞 (Manner assimilation) | irregular, irrational |

<span style="color:#dd6b20;">**현직쌤 팁**</span>: im-/iŋ-는 **Place** 동화, il-/ir-는 **Manner** 동화. 같은 prefix에서 다른 유형의 동화가 작동한다 — 이 구별이 출제 포인트다.

---

### 4) Voice Assimilation — 복수·과거 형태소

English inflectional suffixes -s와 -ed의 voicing은 preceding stem-final segment를 따른다. voiceless segment 뒤에서는 -s → [s], -ed → [t]이고, voiced segment 뒤에서는 -s → [z], -ed → [d]이다. sibilant 뒤의 -s는 [əz], alveolar stop /t, d/ 뒤의 -ed는 [əd]로 실현된다.

<span style="color:#3182ce;">**Voice assimilation**</span>: **Progressive** — preceding consonant의 voicing을 뒤의 morpheme이 복사.

**복수 -s 교체**:
- cats [s], taps [s], picks [s] — voiceless segment 뒤
- dogs [z], cabs [z], tags [z] — voiced segment 뒤
- buses [əz], churches [əz] — sibilant 뒤 (schwa 삽입)

**과거 -ed 교체**:
- walked [t], pushed [t], sipped [t] — voiceless segment 뒤
- robbed [d], seemed [d], swayed [d] — voiced segment 뒤
- tested [əd], blended [əd] — alveolar stop /t, d/ 뒤

**어휘 내 regressive voice assimilation** (뒤의 /t/가 앞 음을 무성화):
- have to [hæftə]: /v/ → [f] before /t/
- has to [hæstə]: /z/ → [s] before /t/
- used to [juːstə]

---

### 5) Manner Assimilation — il-/ir- 배분과 모음 비음화

**Manner assimilation**에서는 target이 adjacent sound의 manner feature를 따른다. negative prefix /iN-/의 il-/ir- pattern은 liquid manner assimilation으로, **Vowel nasalization**은 following nasal consonant 앞에서 나타나는 regressive manner assimilation으로 정리한다.

<span style="color:#3182ce;">**Manner assimilation**</span>: manner feature의 동화.

**Liquid assimilation (il-/ir-)**: /n/ (nasal stop) → \[l] (lateral) 또는 \[r] (rhotic) — manner feature가 바뀜.

```
/in + legal/  → il-legal   [ɪl-]: /n/ → [l] before /l/
/in + regular/ → ir-regular [ɪr-]: /n/ → [r] before /r/
```

**Vowel nasalization**: vowel이 following nasal consonant 앞에서 nasalized되는 regressive manner assimilation.
- band [bæ̃nd], farm [fɑ̃ːrm], can [kæ̃n]

<span style="color:#c53030;">**2010 Q31**</span> — Place assimilation rule 적용: /n/ → [m]/[ŋ] 환경에서 regressive 방향, trigger(뒤 consonant), target(앞 /n/)을 판별.

<span style="color:#c53030;">**2011 Q30**</span> — 음운 규칙과 Assimilation 현상 적용.

<span style="color:#c53030;">**2015 기입1**</span> — Voice assimilation rule 적용: 복수 -s, 과거 -ed의 [s]/[z], [t]/[d] 교체 조건. Progressive voice assimilation.

<span style="color:#c53030;">**2017 기입1**</span> — nasal assimilation 규칙 환경 파악: in+possible → impossible. /n/ → [m] / ___ [p] (bilabial). Regressive place assimilation 확인.

<span style="color:#c53030;">**2020 B-3**</span> — il-/ir- 배분 조건: 어근 첫 자음이 /l/이면 il-, /r/이면 ir- 선택. Liquid manner assimilation 원리 적용.

## ③ 키텀 비교

### Place vs Voice vs Manner

| | Place Assimilation | Voice Assimilation | Manner Assimilation |
|---|---|---|---|
| **동화되는 feature** | place | voicing | manner |
| **방향** | Regressive (영어) | Progressive (주로) | Regressive (모음비음화), Total (il-/ir-) |
| **핵심 예** | /n/ → [m] before /b,p/ | cats [s] / dogs [z] | il-legal, ir-regular |
| **임용 연결** | iN- prefix, ten+N | -s/-ed 교체, have to | il-/ir- 배분, vowel nasalization |

### Progressive vs Regressive 요약

| | Progressive | Regressive |
|---|---|---|
| Trigger 위치 | 앞 | 뒤 |
| Target 위치 | 뒤 | 앞 |
| 영어 빈도 | 드묾 | 흔함 |
| 대표 케이스 | -s/-ed voice assimilation | Place assimilation, iN- prefix |

### Total vs Partial

| | Total | Partial |
|---|---|---|
| 결과 | 두 음이 완전히 동일 | 일부 feature만 공유 |
| 이명 | gemination (겹자음화) | — |
| 예 | give me [ɡɪmmi], good boy [ɡʊbbɔɪ] | ten boys [tɛm bɔɪz] (/n/→[m]: nasal 유지, place만 변화) |

## ④ 수험 팁

### 답안 작성 패턴 — Assimilation 분석

임용 Assimilation 문항 표준 답안 패턴:

> *"In [word/phrase], /X/ undergoes [place/voice/manner] assimilation. The trigger is [Y], which is [bilabial/velar/voiceless/...]. The target /X/ assimilates to [Y]'s [place/voicing/manner] feature, resulting in [Z]. This is a [progressive/regressive], [total/partial] assimilation."*

iN- prefix 답안 패턴:
> *"The negative prefix /iN-/ undergoes regressive place assimilation. Before bilabial /p/, /n/ → [m], yielding im-. Before velar /k/, /n/ → [ŋ], yielding surface [ɪŋ-]. Before alveolar consonants, the underlying /n/ is retained."*

### 함정 정리

<span style="color:#c53030;">**⚠️ /n/ Place assimilation은 Regressive**</span>: ten boys에서 following /b/가 preceding /n/의 place를 결정한다(뒤→앞). Progressive와 혼동 금지.

<span style="color:#c53030;">**⚠️ il-/ir-는 Place가 아니라 Manner 동화**</span>: /n/이 [l] 또는 [r]로 바뀌는 것은 place가 아니라 manner feature의 변화. im-/iŋ-와 다른 동화 유형임을 명시해야 함.

<span style="color:#c53030;">**⚠️ -s/-ed 교체는 Progressive**</span>: 앞 음의 voicing이 뒤의 형태소에 영향 → progressive voice assimilation. Place assimilation과 방향이 다름.

<span style="color:#c53030;">**⚠️ Total vs Partial 혼동 주의**</span>: ten boys에서 /n/ → [m]은 Partial (nasal feature 유지, place만 변화). give me에서 /v/ → [m]은 Total (완전히 동일한 음).
